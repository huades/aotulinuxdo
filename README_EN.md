# aotulinuxdo

English | [简体中文](README.md)

`aotulinuxdo` is a local Google Chrome extension for [linux.do](https://linux.do/), migrated from the enhanced linux.do helper userscript. It provides automatic topic reading, smooth scrolling, reading statistics, account information, and optional automatic likes.

## Features

- Runs locally as a Chrome Manifest V3 extension without a userscript manager.
- Fetches topics and reads them with smooth scrolling, pauses, and small trajectory variations.
- Uses Pointer/Mouse event sequences for topic links, like buttons, and dialog controls.
- Stores daily reading totals, current-session state, and topic history.
- The “Recent 100-day views” value comes from the account card's “Posts read” row. For example, `18142/20000` is displayed as `18142`.
- The account view count is refreshed only when reading starts, reading finishes or is stopped, or the number is clicked manually.
- Topic navigation, page reloads during reading, extension reinjection, and restored tabs do not refresh the account view count.
- `html2canvas` is bundled locally; the extension does not execute remotely hosted code.

## Installation

1. Download or clone this repository.
2. Open `chrome://extensions/` in Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the repository root directory.
6. Open or refresh `https://linux.do/`.

After updating local files, click **Reload** for the extension on `chrome://extensions/`, then refresh the linux.do page.

## Account View Refresh Rules

| Event | Refreshes the value |
| --- | --- |
| Click “Start reading” | Yes |
| Reading finishes or is stopped | Yes, after a short delay |
| Click the view-count number | Yes |
| Navigate automatically to another topic | No |
| Reload a page during reading | No |
| Reinject the extension or restore a tab | No, cached value only |

The account card uses a `current/required` format. The extension reads only `current` and never treats the requirement on the right as the view count.

## Permissions

- `storage`: stores extension settings and state.
- `linux.do` and `idcflare.com`: run the content script.
- `connect.linux.do`: retrieves account trust-level information.

The extension does not request `chrome.debugger`. Pointer/Mouse events generated by a content script are not hardware-trusted browser events.
